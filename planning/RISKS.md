# Risks

| Risk | Likelihood | Impact | Mitigation | Status |
|---|---:|---:|---|---|
| **Plaintext-era API keys not rotated.** Supabase service key, Anthropic key and Resend key sat in local plaintext on the operator's machine. | Low | Medium | **Downgraded and closed by decision 2026-08-10 (Ray).** Investigation found no `.env` file was ever committed and no real credential appears in any tracked file; the only pattern matches are 10-to-20-character placeholders in `.env.example` and `planning/sprints/002-ai-nudges/blueprint.md`. Exposure was local-machine only, never the repository, so the original "High" rating was wrong. Not rotated. If revisited: `api/.env` is mode 644 where the root `.env` is 600. | **Closed — accepted** |
| **Production deploys from a feature branch, not `main`.** | High | Medium | **Resolved 2026-08-10 (Sprint 021).** Both Render services repointed to `main`; the switch was a fast-forward. Push to `main` to deploy. | **Resolved** |
| **No deploy is ever verified by command.** Every production deploy since 2026-07-02 has closed on "it looks up," including the Sprint 021 redeploy that shipped the price guard. No health check, no exercised API call, no CORS confirmation. A broken backend or a CORS block would not be noticed until a user hit it. | Medium | **High** | A verification script was proposed in Sprint 021 and declined. Gap now carried since Sprint 017. Minimum interim check: add a custom line at a 0 rate and confirm submit-for-review is blocked. | **Active — accepted** |
| **A price nobody proofread reaches a client PDF.** 639 numbers were typed by hand across 20 tabs. Two transposition errors are already proven (`I0042` Right Seat Driver OT priced at 800 instead of 80, on the Lucid and MB tabs). | High | High | The importer emits a dry-run exception report and refuses to guess: overtime conflicts and orphans are listed for operator resolution, never auto-resolved. Any overtime rate exceeding 50% of its parent rate is flagged as suspect. | Mitigated by design (Sprint 020) |
| **An unpriced item silently becomes a $0 line on a client-facing estimate.** Four `unit_rate ?? 0` coercion sites turn a missing price into zero with no signal. | High | High | Sprint 020's no-price guard: flag in the picker, banner on Summary, and block the `estimate → in_review` transition. | Mitigated by design (Sprint 020) |
| **Corporate-structure estimates report ~100% gross profit** because no cost is recorded on the corporate path. Makes the GP threshold meaningless for those events. | High | Medium | Known and deliberately deferred to Sprint 025. Beta is office-first. Flag to Dave before any corporate event runs through the app for real. | **Active — accepted for beta** |
| Sprint 020 widens from "load prices" into cost modelling, catalog amendments, or client settings. | Medium | Medium | Scope fixed with Ray 2026-07-27: prices only. `must_not` in the handoff contract is explicit; the four catalog questions are routed to DriveShop, not built. | Active |
| Builder writes to the database directly instead of emitting reviewable SQL. | Low | High | Mirror `import_intacct_catalog.py`: dry-run → `--confirm` writes `.sql` → **operator** applies via Supabase. The script never opens a DB connection. | Active |
| Builder changes source before understanding context. | Medium | High | Handoff requires reading the sprint files and inspecting the named source files before any edit, and stopping at the code gate. | Active |
